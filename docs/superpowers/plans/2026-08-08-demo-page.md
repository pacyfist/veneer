# no-ai Demo Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the nine-section `@pacyfist/no-ai` demo page described in `docs/superpowers/specs/2026-08-08-demo-page-design.md`, where every library feature is demonstrated by evidence the visitor's own browser produces.

**Architecture:** One route, one page, nine section components under a shell that owns the navbar, theme toggle and width cap. Sections that demonstrate a configuration other than the shell's create a child `EnvironmentInjector` carrying their own `provideNoAi`, and render a specimen component inside it via `NgComponentOutlet`. Shared presentation lives in three small `ui/` components.

**Tech Stack:** Angular 21.2 (standalone, signals, `@if`/`@for` control flow, `OnPush`), Tailwind 4, daisyUI 5.7.16, `@pacyfist/no-ai` consumed from `dist/` through the workspace path alias.

## Global Constraints

- **Build the library first.** The demo imports `@pacyfist/no-ai` through a path alias that resolves to `dist/`. Run `npm run build:lib` before any `ng build demo` or `ng serve demo`, or imports fail. `npm start` and `npm run build` already chain it.
- **daisyUI stock components only.** Use `card`, `badge`, `navbar`, `stats`, `mockup-code`, `mockup-browser`, `tabs-lift`, `alert`, `kbd`, `table`, `toggle`, `range`, `select`, `checkbox`, `divider`, `link`. Write bespoke CSS only where daisyUI has no component. All verified present in `node_modules/daisyui/components/`.
- **Themes stay as configured.** `styles.css` declares `light --default, dark --prefersdark`. Do not add or change themes. The navbar toggle uses daisyUI's `theme-controller` class, which works with pure CSS via `:root:has(.theme-controller[value=dark]:checked)`.
- **Content width:** `max-w-5xl mx-auto px-4`.
- **No tests.** Do not create `.spec.ts` files, do not restore `e2e/`, do not touch `.github/workflows/deploy.yml`. This is a deliberate scope decision.
- **Page copy uses hyphens, never em dashes or en dashes.**
- **Every component:** `ChangeDetectionStrategy.OnPush`. Standalone is the Angular 21 default, so no `standalone: true`.
- **Before every commit:** run `npx prettier --write <files>` and re-stage.
- **Commit messages:** one line, Conventional Commits, lowercase, no body.

## Two traps that will silently produce a broken page

Read these before Task 3. Both fail quietly rather than erroring.

**1. Child injectors inherit the shell's seed unless you pass one.**
`NoAiFontService` computes its seed as:

```ts
this.config.seed ??
  (this.isBrowser ? this.transferState.get(SEED_KEY, randomSeed()) : randomSeed());
```

On the browser, `TransferState` already holds the seed the prerender baked in. A child injector with no explicit `seed` therefore reproduces the shell's cipher exactly, and sections 02 and 05 demonstrate nothing while looking like they work. **Every child config must pass `seed: randomSeed()`**, imported from `@pacyfist/no-ai`.

**2. Each isolated instance forges its own font.**
`font-source.ts` caches the `.ttf` bytes so the network fetch happens once, but `forgeScrambledFont` runs per instance: an opentype parse plus a 94-glyph build. Keep the number of simultaneous live instances small. This plan uses at most five, created lazily where practical.

`projects/demo/src/app/ui/isolated-instance.ts`:

```ts
import { NgComponentOutlet } from '@angular/common';
import {
  ChangeDetectionStrategy,
  Component,
  DestroyRef,
  EnvironmentInjector,
  computed,
  createEnvironmentInjector,
  inject,
  input,
} from '@angular/core';
import { NoAiConfig, provideNoAi, randomSeed } from '@pacyfist/no-ai';
import { baseFontBuffer } from '../font-source';
import { SpecimenCard } from './specimen-card';

/**
 * Renders one specimen under its own `provideNoAi`.
 *
 * The seed is drawn here rather than left to the library. On the browser the
 * library falls back to the seed `TransferState` carries from the prerender, so
 * an instance without an explicit seed would silently reproduce the shell's
 * cipher and demonstrate nothing.
 */
@Component({
  selector: 'app-isolated-instance',
  changeDetection: ChangeDetectionStrategy.OnPush,
  imports: [NgComponentOutlet],
  template: `
    <ng-container
      [ngComponentOutlet]="card"
      [ngComponentOutletEnvironmentInjector]="injector()"
      [ngComponentOutletInputs]="{ text: text() }"
    />
  `,
})
export class IsolatedInstance {
  readonly text = input.required<string>();
  readonly config = input<Partial<NoAiConfig>>({});

  protected readonly card = SpecimenCard;

  private readonly parent = inject(EnvironmentInjector);
  private readonly destroyRef = inject(DestroyRef);

  protected readonly injector = computed(() => {
    const child = createEnvironmentInjector(
      [
        provideNoAi({
          font: baseFontBuffer,
          fallbackFontFamily: "'Roboto', sans-serif",
          seed: randomSeed(),
          ...this.config(),
        }),
      ],
      this.parent,
    );
    this.destroyRef.onDestroy(() => child.destroy());
    return child;
  });
}
```

import { ChangeDetectionStrategy, Component, computed, signal } from '@angular/core';
import { buildScrambleMap, randomSeed } from '@pacyfist/no-ai';
import { SectionHeading } from '../ui/section-heading';

interface Pair {
  readonly from: string;
  readonly to: string;
}

/**
 * The substitution table, built from a seed drawn in the browser.
 *
 * Deliberately does not use the shell's map. The deployed site is prerendered,
 * so the shell's seed is identical for every visitor, and a table built from it
 * could not show what a per-load cipher looks like.
 */
@Component({
  selector: 'app-cipher-table',
  changeDetection: ChangeDetectionStrategy.OnPush,
  imports: [SectionHeading],
  template: `
    <app-section-heading num="02" title="The cipher" />
    <p class="text-base-content/60 mb-4 max-w-3xl text-sm leading-relaxed">
      The substitution this instance drew. No character maps to itself, which the library guarantees
      by construction: a plain shuffle leaves some letters in place, so it swaps those out
      afterwards. Space is excluded on purpose, because it is the only character the browser can
      break a line at.
    </p>

    <div class="card bg-base-100 shadow-sm">
      <div class="card-body p-4">
        <div class="mb-3 flex flex-wrap items-center gap-3">
          <button class="btn btn-sm btn-primary" (click)="redraw()">draw a new cipher</button>
          <span class="font-mono text-xs">seed {{ seed() }}</span>
          <span class="badge badge-ghost badge-sm">{{ pairs().length }} pairs</span>
        </div>
        <div class="overflow-x-auto">
          <table class="table table-zebra table-xs font-mono">
            <tbody>
              @for (row of rows(); track $index) {
                <tr>
                  @for (pair of row; track pair.from) {
                    <td class="whitespace-nowrap">
                      {{ pair.from }} <span class="text-base-content/40">-&gt;</span>
                      <span class="text-primary">{{ pair.to }}</span>
                    </td>
                  }
                </tr>
              }
            </tbody>
          </table>
        </div>
      </div>
    </div>

    <p class="text-base-content/50 mt-3 text-xs leading-relaxed">
      Full disclosure: the page's own specimen does not get a fresh cipher like this one. The site
      is prerendered as static files, so one seed is baked in at build time and every visitor sees
      it. This table runs its own client-side instance to show what a per-load cipher looks like.
    </p>
  `,
})
export class CipherTable {
  private static readonly SHOWN = 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789';
  private static readonly PER_ROW = 8;

  protected readonly seed = signal(randomSeed());

  protected readonly pairs = computed<readonly Pair[]>(() => {
    const map = buildScrambleMap(this.seed());
    return [...CipherTable.SHOWN].map((from) => ({
      from,
      to: String.fromCodePoint(map.forward.get(from.codePointAt(0)!)!),
    }));
  });

  protected readonly rows = computed<readonly (readonly Pair[])[]>(() => {
    const all = this.pairs();
    const out: Pair[][] = [];
    for (let i = 0; i < all.length; i += CipherTable.PER_ROW) {
      out.push(all.slice(i, i + CipherTable.PER_ROW));
    }
    return out;
  });

  protected redraw(): void {
    this.seed.set(randomSeed());
  }
}

              class="text-primary overflow-x-auto font-mono text-xs whitespace-pre-wrap"

      apart from one the browser rendered itself. Without it the client would take the server's
      ciphertext for the original and scramble it a second time, and the font only ever undoes one
      layer.
    </p>
  `,

export class ServedSource {
  private readonly document = inject(DOCUMENT);

  protected readonly url = signal('');
  protected readonly status = signal<Status>('loading');
  protected readonly markup = signal('');
  protected readonly error = signal('');

  constructor() {
    afterNextRender(() => void this.load());
  }

  private async load(): Promise<void> {
    const href = this.document.baseURI;
    this.url.set(href);

    try {
      const response = await fetch(href, { cache: 'no-store' });
      if (!response.ok) {
        throw new Error(`${response.status} ${response.statusText}`);
      }
      const html = await response.text();
      const parsed = new DOMParser().parseFromString(html, 'text/html');
      const protectedEl = parsed.querySelector('[data-no-ai-ssr]');

      if (!protectedEl) {
        this.error.set(
          'No element carrying data-no-ai-ssr was found in the response. On a dev server without SSR this is expected.',
        );
        this.status.set('error');
        return;
      }

      this.markup.set(protectedEl.outerHTML);
      this.status.set('ok');
    } catch (cause) {
      this.error.set(`Could not fetch this page's own HTML: ${(cause as Error).message}`);
      this.status.set('error');
    }
  }
}

## Self-review notes

**Spec coverage.** All nine sections map to Tasks 4 through 12. The two-tier injector architecture is Task 3. Error handling for the section 03 fetch is in Task 6 Step 1, and the clipboard fallback is resolved in Task 10 by using the `copy` event instead of the permissioned API. The three disclosures land in Task 4 Step 1 (bundle plaintext), Task 5 Step 1 (baked seed) and Task 10 (README wording). Accessibility is enforced per-component and audited in Task 13 Step 3. Tests are absent by design.

**Defects found and fixed during self-review.** Recorded because each would have shipped a page that looked right and argued nothing.

1. **The mirror's readable side was plain text.** The hero would have shown "what you see" as an ordinary unprotected paragraph while claiming it was protected. Anyone opening devtools would have found it readable. `MirrorPanel` now renders that side through the pipe with `noAiFont`, which is also the form the README prescribes for bound text.
2. **Nothing carried the SSR marker.** Task 1 removes the old specimen from `app.html`, so no element would have had `data-no-ai-ssr` and section 03 would have shown its "not found" error on every load. The hero now owns a static protected specimen in element-content form, which is the only form scrambled during prerender.
3. **The pipe snippet would have been evaluated.** `[lines]="['<h3 noAiFont>{{ title() | noAi }}</h3>']"` is parsed by Angular as interpolation inside a binding, not as a literal. All four snippets moved to a module-scope `SNIPPETS` constant.
4. **The Task 13 grep would have failed falsely.** `haystack` appeared both in the protected specimen and in the unprotected sentence explaining it, so the served HTML would always have contained it. The explanation no longer repeats the word.
5. **`announced` and `kernSample` were `signal`, not `computed`.** They would have kept showing ciphertext after a font failure had flipped the library to passthrough, which is precisely the dishonesty this page exists to avoid.

**Known gap carried deliberately.** Task 7 Step 1 leaves one sentence of copy to be chosen between two fully written alternatives, because whether `[noAi]="expr"` renders during prerender depends on Angular 21 effect timing and cannot be settled by reading the library source. The plan defaults to `BOUND_NOTE_B`, the more conservative claim. This is the one value decided during implementation rather than in the plan, and Defect 2 above depends on it: if branch A turns out to be true, the hero could use a binding for its specimen, but the plan does not rely on that.
